# [필수] 팀을 이뤄 협업을 하면서 성과를 이뤘던 경험을 적어주세요. 자신이 어떤 역할로 팀에 기여했고 어떤 교훈을 얻었는지를 포함해 주세요. (단, 학교 팀 과제를 수행한 경우는 제외)

2026년 2월 와플스튜디오 해커톤에서 매장 미션을 인증하면 코인을 받는 앱 localhost로 금상을 받았습니다. 팀원 세 명이 서버를, 저는 모바일 앱을 혼자 맡았습니다. 코드는 AI 에이전트에 맡기고, 저는 서버 API를 읽었습니다.

API는 마감 8시간 전에야 올라왔고 밤새 바뀌었습니다. 그런데 구조는 반복됐습니다. 다섯 미션 모두 '시도'라는 자원을 POST로 만들고 GET으로 읽었고, 응답은 늘 상태, 안내문, 보상 번호였습니다.

팀원들은 서버 운영만으로 이미 벅차 보였습니다. 그래서 묻는 대신 틀린 요청을 보냈습니다. 20분 체류 미션에 3분 만에 체크아웃하면 '남은 시간 17분'이 돌아왔습니다. 마감 뒤 AI 서버가 통째로 바뀌어도 앱은 한 줄도 고치지 않았습니다.

이 공통 인터페이스는 마감 앞에서 비즈니스 로직을 정하는 팀의 의사소통 비용을 줄였습니다. RESTful API와 CRUD도 현실의 웹 개발에서 비슷한 기능을 해 온 건 아닐까 생각했습니다.
