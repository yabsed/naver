# BMW Financial Services Korea
### IT Intern - AI Engineering 지원 자기소개서

BMW Financial Services Korea의 AI Engineering 인턴십 공고를 읽고, 저는 지원서를 작성하기에 앞서 작은 체스 웹 애플리케이션을 개발하기 시작했습니다. 공고에서 요구하는 Python/FastAPI와 AWS EC2·ECS를 실제로 다뤄보고 싶었기 때문입니다. 저에게 Chess는 체스 게임을 만드는 프로젝트라기보다, 웹 서비스가 클라우드에 배포되고 운영되는 과정을 이해하기 위한 학습 프로젝트였습니다.

웹 개발 자체가 처음은 아니었습니다. 2021년에는 Django 기반 대학 시간표 서비스의 백엔드 개발에 참여했고, 2026년 초에는 React 기반 중고거래 플랫폼의 프런트엔드를 개발했습니다. 같은 해 9월에는 AI를 적극적으로 활용해 Markdown 편집기, 브라우저, 터미널, Monaco 편집기와 언어 서버를 통합한 데스크톱 애플리케이션 Setdown을 만들었습니다. 이 과정에서 AI가 복잡한 소프트웨어를 놀라울 만큼 빠르게 구현할 수 있다는 사실을 경험했습니다. 동시에 프로그램을 작동하게 만드는 것과 그 내부 구조를 이해하는 것은 별개의 일이라는 점도 깨달았습니다.

기존의 프런트엔드·백엔드 개발 경험과 달리, 클라우드 배포와 운영은 제게 익숙하지 않은 영역이었습니다. BMW의 채용공고를 접했을 때 저는 이 부족한 경험을 보완할 기회라고 생각했습니다. 특히 금융 서비스에서는 새로운 기능을 빠르게 구현하는 능력뿐 아니라 시스템의 동작을 이해하고, 변경 사항을 검증하고, 문제가 발생했을 때 원인을 추적하는 능력이 중요하다고 생각했습니다.

Chess에서는 Svelte 프런트엔드와 FastAPI 백엔드, PostgreSQL 데이터베이스를 연결하고 이를 AWS에 배포했습니다. ChatGPT를 활용해 구현 속도를 높이면서도, 학습의 목적에 맞게 불필요한 기능과 복잡성을 줄이고자 했습니다. 이후 AWS CLI와 CloudFormation으로 인프라를 관리하고, GitHub Actions를 통해 컨테이너 빌드와 배포를 자동화했습니다. 배포 전후의 HTTP·WebSocket 연결 검사를 추가하고, AWS 접근 권한을 분리했으며, 운영 비용을 분석해 ARM 기반 EC2 인스턴스로 전환하고 NAT Gateway를 제거했습니다.

이 과정에서 가장 중요하게 생각한 것은 단순히 배포에 성공하는 것이 아니었습니다. 배포 절차를 읽고 추적할 수 있도록 정리하고, 무엇을 검증해야 하는지 파악하는 데 집중했습니다. 물론 파이프라인이 작동한다고 해서 시스템의 모든 부분을 이해하게 된 것은 아닙니다. 서비스를 구축하는 단계는 지나왔지만, 그 구조와 동작 원리를 깊이 이해하는 학습은 이제 시작입니다. 현재도 AI가 작성한 코드와 인프라 설정을 살펴보며 각 구성요소의 역할과 상호작용을 공부하고 있습니다.

저는 이번 프로젝트를 통해 AI를 활용하면 새로운 기술에 훨씬 빠르게 접근할 수 있지만, 그 결과를 이해하고 검증하는 과정까지 생략할 수는 없다는 사실을 배웠습니다. BMW Financial Services Korea의 AI Engineering 인턴으로서 이러한 학습 태도를 실제 업무에 적용하고 싶습니다. Python/FastAPI 기반 서비스 개발과 AWS 배포 경험을 바탕으로 업무에 기여하는 동시에, LLM 기반 서비스의 안정적인 운영과 검증 방법을 배우겠습니다. AI가 구현의 장벽을 낮춰준 만큼, 저는 그 결과를 이해하고 책임질 수 있는 엔지니어로 성장하고 싶습니다.
